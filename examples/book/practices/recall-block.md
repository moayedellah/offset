# Practice — closed-book recall block

`unseen`, and honestly so: this practice has been *designed* and not *run*. It
is in the vault because the scheduler is the right place to declare the
intention, and because an intended practice with no first rep is the honest
state.

## The design

Fifteen minutes, no book, no screen. Name the claims from the current subject
and write the answer from memory before checking anything. Then open the vault
and grade each one.

The order is the whole design: **attempt first, lookup second.** Reversing it
produces the feeling of studying and none of the effect, which is the finding
that motivates this entire project [cite: roediger2006].

## What would make it `proven`

A `proof` note at any rung, whose `artifact` is the block itself, plus what
surprised me in it. Not a checkbox. `L4` would refuse `proven` without that
proof, which is the intended irritation.
