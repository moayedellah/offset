# Insight — admitting the demo is the feature

This vault is deliberately empty of anyone's real life, and `TODO.md` names the
five facts a machine must not invent.

The instinct is to fill it in, because an example with content reads as more
complete. That instinct is the failure mode the whole project is built against:
presenting a construction as though it were a finding, `kind: source` on an
inference, a summary standing in for a source you did not read.

An honest skeleton plus a visible list of gaps teaches more than a smooth
fiction. **The gaps are the demonstration.**
