# ILLUSTRATIVE — closed-book recall block

`unseen`, honestly: designed, not run. An intended practice with no first rep
is the truthful state, and it is why this example is more useful than a
completed one.

Fifteen minutes, no book, no screen: name the claims in the current subject and
answer from memory before checking anything. **Attempt first, lookup second.**
Reversing that order produces the feeling of studying and none of the effect
[cite: roediger2006], which is the finding that motivates this entire project.

## What would make it proven

A `proof` note with `practice: recall-block`, whose `artifact` is the block and
records what surprised you. Not a checkbox — `L4` refuses `proven` without that
proof, and the irritation is intended.
